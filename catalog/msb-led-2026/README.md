## 우편용과 이메일용은 이렇게 다릅니다

**우편용 (종이)**
- A4 4쪽. 2쪽과 3쪽이 펼침면으로 짝이 맞게 짜여 있어서 A3 한 장을 반으로 접는 4면 리플렛으로 만들면 가장 보기 좋습니다. A4 두 장 양면으로 뽑아도 됩니다.
- 종이에서는 링크를 누를 수 없으니 뒷면에 전화번호를 크게, 문의 페이지 QR 코드를 넣었습니다.
- 사진은 인쇄 해상도(200~400ppi)로 들어가 있습니다.
- 인쇄소용 파일은 사방에 3mm 재단 여백이 붙어 있습니다. 주문할 때 "작업 사이즈 216×303, 재단 사이즈 A4(210×297)"라고 적으면 됩니다.
- 색은 화면용(RGB)으로 저장돼 있습니다. 인쇄소에서 인쇄용(CMYK)으로 바꿀 때 조금 차이가 날 수 있으니, 처음 주문할 때는 시안(교정쇄)을 한 번 받아 보세요. 인쇄 때 크게 변하지 않는 차분한 색만 썼습니다.
- 종이는 아트지나 스노우지 150~200g 정도를 추천합니다.

**이메일용 (화면)**
- PC 모니터에 꽉 차는 16:9 가로 화면 6장입니다.
- 용량이 작아서(약 1.3MB) 받는 쪽 메일함에서 바로 열립니다.
- 전화번호, 메일 주소, 홈페이지는 누르면 바로 연결됩니다. 메일 주소를 누르면 제목이 "MSB 부스, LED 배너 상담 문의"로 채워진 새 메일이 열립니다.
- 마지막 장에 QR 코드도 넣어서 PC로 보던 사람이 휴대폰으로 찍어 문의 페이지를 열 수 있습니다.

## 보내기 전에 확인할 것

1. **QR 코드 주소**: 기존 카탈로그와 같은 `https://www.e-isb.com/contact/` 로 연결됩니다. 지금 이 저장소의 새 홈페이지에는 `/contact/` 페이지가 없고 첫 화면 안에 문의 영역(`#contact`)만 있습니다. 새 홈페이지로 바꾼 뒤에도 이 주소가 열리는지 휴대폰으로 한 번 찍어 확인해 주세요.
2. **LED 배너 화면 속 내용**: 공급사 사진의 워터마크를 지우고, 화면에는 "어서 오세요 / 오늘 일정", "회의 부스 예약 없이 쓰세요" 같은 예시 화면을 넣었습니다. 카탈로그에 "화면 속 내용은 예시입니다"라고 적어 두었습니다.
3. **회사 소개 문장**: "KINTEX, BEXCO 같은 전시장에서 트러스 구조물과 투명 LED를 설치해 온 회사입니다"는 홈페이지 시공 사례(KORMARINE 2025 BEXCO, SEOUL FOOD 2025 KINTEX, G-TLD 사례)를 근거로 썼습니다.
4. **견적**: 상담 3단계에 "사양과 납기, 견적을 정리해 보내드립니다"라고 넣었습니다. 견적을 따로 안내하지 않으면 이 부분을 지워 주세요.
5. **사진**: 부스 사진에 제조사 로고(ARS Pod, soundbox)가 보입니다. 원래 카탈로그에 쓰던 제조사 제공 사진 그대로입니다.

## 문구를 고치고 다시 만들려면

1. `src/print.html` (우편용) 또는 `src/email.html` (이메일용)에서 글자를 고칩니다.
2. 이 폴더에서 아래 명령을 실행하면 PDF 세 개가 다시 만들어집니다. 글꼴이 없으면 자동으로 받아옵니다.

```bash
node scripts/build.mjs
```

LED 배너 사진을 다시 손볼 때만 아래 두 줄을 먼저 실행합니다 (Python의 numpy, scipy, pillow 필요).

```bash
node scripts/render-screens.mjs
python3 scripts/prepare-images.py
```

## 폴더 구성

- `src/print.html`, `src/email.html` : 카탈로그 원본 (HTML)
- `src/screens/` : LED 배너 화면에 넣은 예시 화면
- `src/img/source/` : 원래 카탈로그에서 꺼낸 원본 사진
- `src/img/` : 손본 LED 배너 사진, QR 코드, 이메일용으로 줄인 사진
- `scripts/` : PDF와 이미지를 만드는 스크립트
