## 두 버전의 차이

| | IT·사무실용 | 공장용 |
| --- | --- | --- |
| 표지 | 회의실은 회의할 때만 쓰세요 | 기계 소리에서 잠깐 벗어나는 자리 |
| 부스 설명 | 혼자 하는 통화에 회의실 하나를 통째로 쓰는 문제 | 라인 옆에서는 전화 한 통도 쉽지 않은 문제, 쉬는 시간에 쉴 곳 |
| LED 배너 | X배너 대신 로비, 행사장 안내 화면 | 견학, 바이어 방문 때 출입구 안내와 안전 수칙 |
| 활용 표 | 업무 공간, 라운지, 회의실 옆, 로비 | 생산동 사무 구역, 휴게실 옆, 협력사 미팅, 출입구, 견학 동선 |

## 디자인

- 홈페이지와 같은 짙은 배경과 황동색(골드)을 썼습니다.
- 표지에 큰 "MSB" 글자를 넣고, 사진은 페이지 가장자리까지 채워서 배경으로 자연스럽게 이어지게 했습니다.
- 모델명(S, SM, M, M2, ML, L)과 전화번호는 크게 넣어 멀리서도 눈에 띄게 했습니다.
- 글꼴은 한글 [원티드 산스(Wanted Sans)](https://github.com/wanteddev/wanted-sans), 큰 영문과 숫자는 [Big Shoulders](https://github.com/xotypeco/big_shoulders)입니다. 둘 다 무료이고 상업용으로 쓸 수 있습니다(SIL OFL).
- 문구는 "AI가 쓴 것 같은" 표현(짝 맞춘 문장, "~를 위한 공간", "~에서 ~까지", 가운뎃점 나열, 영문 대문자 소제목, 순서 없는 01/02/03 번호)을 빼고 실제 상황으로 썼습니다. 기준은 [daleseo/korean-skills](https://github.com/daleseo/korean-skills), [nomadamas/k-skill](https://github.com/nomadamas/k-skill), [anthropics/skills](https://github.com/anthropics/skills), [pbakaus/impeccable](https://github.com/pbakaus/impeccable)의 점검 목록입니다.

## 인쇄할 때

- A3 한 장을 반으로 접는 4면 리플렛으로 만들면 2쪽과 3쪽이 펼침면이 됩니다. A4 두 장 양면으로 뽑아도 됩니다.
- 인쇄소에는 `인쇄소용(재단여백3mm)` 파일을 올리고 "작업 사이즈 216×303, 재단 사이즈 A4(210×297)"라고 적으면 됩니다.
- 배경이 어두워서 코팅된 종이(아트지 150~200g, 무광 코팅 추천)에 뽑아야 색이 깊게 나옵니다. 처음 주문할 때는 시안(교정쇄)을 한 번 받아 보세요. 파일은 화면용 색(RGB)이라 인쇄용 색(CMYK)으로 바뀌면서 조금 달라질 수 있습니다.
- 사무실 프린터는 종이 가장자리까지 인쇄하지 못해서 테두리에 흰 여백이 생깁니다. 업체에 보낼 것은 인쇄소에 맡기는 걸 권합니다.

## 보내기 전에 확인할 것

1. **"벽을 세우는 공사 없이 들여놓는다"** (IT용 2쪽, IT 메일 본문): 부스는 보통 공사 없이 설치하지만 ARS POD의 설치 조건(전원 연결 등)을 확인하고 써 주세요.
2. **"문을 닫으면 바깥 소리가 줄어든다"** (공장용): 수치는 넣지 않았습니다. 차음 성능은 "상담 때 안내"로 적었습니다.
3. **공장 사진**: 지금 사진은 모두 사무실에 놓인 부스입니다. 공장이나 현장에 설치한 사진이 있으면 공장용 표지와 2쪽에 넣었을 때 훨씬 설득력이 있습니다.
4. **QR 코드**: 기존과 같은 `https://www.e-isb.com/contact/`로 연결됩니다. 새 홈페이지로 바꾼 뒤에도 이 주소가 열리는지 확인해 주세요.
5. **견적**: 상담 3단계에 "사양과 납기, 견적을 정리해 보내드립니다"라고 넣었습니다. 견적을 따로 안내하지 않으면 지워 주세요.
6. **회사 소개**: "KINTEX, BEXCO 같은 전시장에서 트러스 구조물과 투명 LED를 설치해 온 회사"는 홈페이지 시공 사례를 근거로 썼습니다.

## 문구를 고치고 다시 만들려면

1. `src/print.html` (우편용) 또는 `src/email.html` (이메일용)에서 글자를 고칩니다.
   - `class="v-it"` 이 붙은 줄은 IT용에만, `class="v-factory"` 가 붙은 줄은 공장용에만 나옵니다. 아무것도 안 붙은 줄은 두 버전에 같이 나옵니다.
2. 이 폴더에서 아래 명령을 실행하면 PDF 여섯 개가 다시 만들어집니다. 글꼴이 없으면 자동으로 받아옵니다.

```bash
node scripts/build.mjs              # 전부
node scripts/build.mjs it           # IT용만
node scripts/build.mjs factory print   # 공장용 우편용만
```

임시 LED 이미지를 다시 만들 때만 아래 두 줄을 먼저 실행합니다 (Python의 numpy, scipy, pillow 필요).

```bash
node scripts/render-screens.mjs
python3 scripts/prepare-images.py
```

## 폴더 구성

- `src/print.html`, `src/email.html` : 카탈로그 원본 (HTML)
- `src/screens/` : 임시 LED 이미지 화면에 넣은 예시 화면
- `src/img/source/` : 원래 카탈로그에서 꺼낸 원본 사진
- `src/img/` : LED 배너 이미지, QR 코드, 이메일용으로 줄인 사진
- `src/display-font/` : 큰 영문 글꼴 (Big Shoulders)
- `scripts/` : PDF와 이미지를 만드는 스크립트
